# 设备资产与流转管理系统 — 用户手册（v1.0.0）

> 适用：Windows 7 SP1（64 位）/ Windows 10 / Windows 11。单机使用，无需联网。
> 配套：`equipment.exe`、`config.yaml`（可自行生成）、`backup/`、`logs/`、`docs/user-guide.md`。

---

## 1. 运行环境与浏览器（重要）

| 系统 | 要求 |
|---|---|
| Windows 10/11 | 任意现代浏览器（Edge/Chrome/Firefox） |
| **Windows 7 SP1 (x64)** | 必须使用 **Chrome 109** 或 **Firefox ESR 115**；**IE 不支持** |

Win7 浏览器获取（需在有网的机器下载后拷贝）：
- Chrome 109 历史离线安装包：在可联网电脑打开
  `https://dl.google.com/chrome/install/109.0.5414.120/chrome_installer.exe` 下载，
  拷到本机双击安装（需管理员）；或使用 Firefox ESR 115。
- 若无法访问 Google，可联系 IT 从内网软件源获取同版本离线包放入 `install/` 目录备用。

## 2. 启动与首次使用

1. 双击 `equipment.exe`（控制台窗口保持开启属正常；关闭窗口=退出程序）。
2. 自动打开浏览器 `http://localhost:8080`（若未自动打开，手动访问该地址）。
3. 首次启动自动完成：建库（equipment.db）→ 建表（含历史索引）→ **自动备份**到 `backup/` → 就绪。
4. 首次数据：进入左侧 **数据导入**，选择公司提供《设备借出总账.xlsx》→ 预览/校验 → 确认导入。

> 说明：导入仅允许"空库首次全量导入"（防覆盖）。如有校验阻断（如重复编号）会跳过并给报告，
> 按报告修正 Excel 后在空库重新导入即可。业务正式使用后**不要再用 Excel 改数据**。

## 3. 页面功能速览

| 菜单 | 用途 |
|---|---|
| Dashboard | 总数/状态/班组/类别统计、最近流转、外借与逾期提醒 |
| 设备台账 | 搜索(编号/名称/型号)、类别/状态/班组筛选、新增/编辑、双击行看详情 |
| **班组设备** | 按「班组 → 设备类别 → 设备」查看各班组当前使用设备；未分配设备（在库/外借/维修）单列便于排查；点设备编号进入既有设备详情 |
| 设备流转 | 与设备台账同入口：详情内按状态提供 出库/转交/入库/外借/归还/送修/维修完成/报废 |
| 外借管理 | 外借单列表（逾期标红）、归还、延期；外借方(公司)维护 |
| 班组管理 | 班组/内部单位（含"双发"分厂）增改、停用（历史保留） |
| 数据导入 | Excel 首次初始化导入 |
| 数据备份 | 手动备份、查看备份、恢复（需输入 RESTORE 确认） |
| 系统设置 | 类别字典、系统信息 |

每个操作都要求填写**操作人**（记住最近一次），并在设备详情生成可追溯的**流转时间线**。

### 班组设备（视图说明）

- **用途**：管理人员快速回答“A班现在用了哪些设备？”——页面按 **班组 → 设备类别 → 设备** 三级分组展示。
- **归属来源**：当前班组取 `equipment.current_team_id`，当前状态取 `equipment.status`（`IN_TEAM` 才计入班组分组）；不扫描历史记录推断归属。
- **未分配设备**：`current_team_id` 为空的设备（在库/外借/维修等）单独成组展示，便于发现未归队设备；外借设备带“外借”状态标签，不会误显示为某班组在用。
- **与流转的关系**：设备在“设备台账 → 详情 → 出库/转交”后，本视图即时反映；历史记录保持完整不受影响。

## 4. 数据与历史

- 数据存 `equipment.db`（请勿手工编辑）。
- **任何一次流转 = 更新当前状态 + 写一条历史**；历史永久保留、界面不提供删除。
- 设备编号一旦确定不可直接修改；录错走"受限更正"（填原因，记录审计）。
- 班组/外借方改名或停用不影响历史（历史记录当时名称）。

## 5. 备份与恢复

- 程序**每次启动自动备份**，也可在"数据备份"页手动备份；默认保留最近 30 份。
- 恢复是危险操作：**系统会先自动备份当前库（安全快照）**，替换后即回到该备份时的状态。
- 备份文件在 `backup/`，形如 `equipment-2026-09-08_104514.db`；`pre-restore-*`/`equipment-*_1.db` 为恢复前安全快照，**不要手工删除**最新的那几份。

## 6. 常见问题（FAQ）

**Q1 双击后"端口 8080 被占用"？**
```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen | Select OwningProcess
Get-Process equipment | Stop-Process -Force   # 关掉旧的程序实例
```
或改 `config.yaml` 的 `port`（如 9090）后重启。

**Q2 页面白屏/不显示？**
先关闭旧实例再启动；浏览器按 Ctrl+F5 强刷。若仍白屏，F12→Console 第一条报错发给维护人员。
（已修复历史问题：空库时统计字段为 null 导致白屏。）

**Q3 我想改设备信息？**
名称/型号/类别/备注：设备详情→编辑；编号：详情→受限更正（需原因）。状态只能在库/班组/外借等之间流转，不能直接"改"状态。

**Q4 这台电脑坏了/换电脑？**
把整个程序目录拷贝到新机器（含 equipment.db 与 backup/）双击即可，数据库自包含。

**Q5 还有哪些事需要开发人员？**
新增"状态类型/流转动作"、加页面/报表/字段、升级依赖 —— 属于版本升级；日常改数据全部在页面完成。

## 7. 防火墙与安全

- 程序只监听 `127.0.0.1`（仅本机），不会对外网开放，通常**不会触发防火墙询问**。
- 若系统仍询问：允许即可（仅本机回环）。
- 单机离线使用，无账号体系；请通过文件系统权限管理使用者。

## 8. 卸载/数据导出

- 卸载 = 删除整个程序目录（如需保留数据先复制 equipment.db 与 backup/）。
- 台账可在"设备台账"页筛选后从 API 导出：`http://localhost:8080/api/export/equipment`（下载 .xlsx，含当前筛选）。
