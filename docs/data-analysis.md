## 3. 物理结构：设备主块（A–F）＋ 借出事件（G–K）

整表由"**设备主块**"构成，每块 = 一组共享（A 类别 + B 名称 + C 型号）的连续行：

- B/C（部分含 A、D、E）在主块上纵向合并；F（编号清单）在块内**逐行续写**（常见每行 ≤8~10 个编号），数量以 **D 合并且只出现于块首**为总台数；
- 借出事件行（G–K）与编号续写行**交错分布在块内**：事件可以独占一行，也可与当行 F 编号共存；
- 编号较多的借出事件会**跨多行续写**（G/H/I 仅在事件首行填写，后续行仅续 J）。

## 4. 数量与编号一致性结论

- **D 合计 2147 = E 非合计行合计 2147 = 合计行(E) 2147** ✓（此前一度出现 4294 系统计误把合计行 E=2147 计入所致，已排除）；
- E 为财务分段口径：段首在块内多处合并（如 R92 E=28、R97 E=70、R106 E=20，28+70+20=118=D；R131 E=20 + R134 E=10 = 30=D）。两处 D≠E 的行均为"段首带 D"形态，**非数量矛盾**；
- F 编号 token 总数 **1666**；去重后纯数字编号 **1443** 个；另有若干字母/混合编号（`2404E0371`、`D4Z72505`、`L02405240017`、`PL0TK00002`、`EDO20150902`、`CNZ602189`、`0612316816` 等）与 566 台"无编号"（85 行，D 合计 566）；
- 由此 `1443 + 混合编号 + 566 < 2147` 存在差值，成因为**编号重复（同块重复与跨块短序号复用）**与可能的口径差异 —— 精确到每块的核对留给导入校验阶段逐块输出（import-rules §5），**不在 Phase 0 妄断**。

## 6. 设备编号规则（识别与风险）

1. 主格式：纯数字（1~8 位，如 `6040`、`11472`、`0612316816`）；部分带字母前缀/混合（如 `L02405240017`、`2404E0371`、`PL0TK00002`）。
2. 短序号（`001`–`023`）被多个不同设备块重复使用（验布机、马连机、三点定位机、超声波接带机等各有自己的 001…），**不是全局唯一**。
3. 全局重复数字 token 92 个；其中一部分为**同块内疑似重复录入**（DDL-9000S 块 R216 `2003 2003`、R218 `2017 2017`、R230–233 `3263–3274` 双写；DDL-9000B 块 R161 `11472`、R167 `12531`、R168 `12538` 双写等），可能造成块内 F 计数多于 D。
4. 疑似 `O/0` 混淆：R317 `O7002`、R394 `O430701`（大写字母 O 处应为数字 0）。
5. F 列个别行是**描述性文本**而非编号：R16 `拉布机配件`（整块"XL-S1程控器 FX2NC-64MT"以描述代替编号）。
6. `无编号`（85 行，566 台）——真实无编号，**不得伪造编号**，用 `internal_code=EQ-xxxxx` 承载身份（决策 6/章程 §14）。
7. J（借出编号）含**括号注释**：`11612（11369（带拖布轮）`、`（2024 2027 4325（带拖布轮）`、`2183（带拖布轮）`、`（3313 2029 2001 1905(带拖布轮）`（全半角括号混用），以及 **`（2026.9.4入南库）`**（R334）、`292020(2026.9.4入南库）`（R340）——"带拖布轮"疑为设备属性/配件、"入南库"疑为归还仓库信息。

## 7. 借出事件分析（G–K）

- 共 **144** 个事件行（G 非空），最早 `2009.4.11`、最新 `2026.8.24`（对照今天 2026-09-07，最近约一个月内）。
- 时间格式：143 行为 `YYYY.M.D`（含 `2021.11.04`、`2022.3.01`、`2026.8.8` 等前导零/不统一写法）；**R337 `2018.4` 缺"日"**。
- **无任何"预计归还/实际归还"列**；归还信息仅零星存在于 J 列括号注释（"入南库"2 例）→ 当前在借情况无法从文件直接判定（W-2 [BLOCK]）。
- I（台数）与当行 J 编号数不一致 9 行（R145/147/151/155/164/170/173/175/195）：经查这些事件编号**延续到下一行 J**（I 仅首行填写），属正常续写；极少数（如 R145 I=10 而 R146 续写 4 个）需按"事件续行"合并理解。
- K 备注仅 2 行：R161 `王成为`、R162 `兰孝发` —— 疑似经办人姓名（operator 来源，W-6）。
- 借出对象同时包含**无编号设备**（R17 `标准光源` J=无编号、R386 包装熨斗 J=无编号、R387）：存在**按台数借出**而非按编号借出的情形 → 外借建模需支持"编号外借"为主、特殊处理无编号批次（W-8）。
- 借出编号原则上应属于本块 F 清单（如打结机块 J=1550 在 F 中），但**跨块引用/错位风险存在**，导入校验须做"J 编号是否在本设备块 F 内"检查并报告不在册编号（W-10）。

## 8. 数据异常报告（按确定性分层）

### 8.1 确定型（不影响语义，导入统一规范化处理）
- A1：A 列区域标注杂糅（§3 表）；R429–R466 无类别。
- A2：编号清单分隔符为空格/换行（含全角空格风险）；首尾多余空格（F/J 大量尾随空格）。
- A3：日期文本格式不统一（`2022.6.14` / `2021.11.04` / `2022.3.01`），解析规则见 import-rules。
- A4：B/C 列含多余空格、全半角括号混用（保留原文展示，入库前 trim）。
- A5：R344–R380 主块标签为 `买…` 形式（归属/来源不明，见 W-1）。
- A6：R350/R381/R415/R428 等整行空档（合并块之间的空行），跳过即可。
- A7：合计行 R467 不导入。

### 8.2 数据疑点（影响正确性，**必须用户确认后处理**，禁止猜测）
- W-1：`买发网厂/买华诺/买针织厂` 标注含义与归属（是"类别"还是"采购来源"？R344–R380 是否并入既有类别？）→ [BLOCK-导入前]
- W-2：**当前在借设备无法判定**（无归还列；仅 2 例"入南库"提示）——**已定 2026-09-08（决策 15）**：导入默认全部"在库"，借出由用户后续手动补录；不再依赖文件判定。
- W-3：同块重复编号（11472、2003、2017、3263–3274 等）：是"两台物理机同号"还是"录入重复"？→ [BLOCK-影响唯一约束]
- W-4：跨设备块重复短序号（001–023 等）：入库时"编号+名称/型号"才能区分 → 唯一约束粒度如何取？见 database-design。
- W-5：H 列"双发分厂（xx）/莒县双发"等是否=内部借调？——**已定 2026-09-08（决策 15）**：名称含「双发」的 4 个单位为**本厂内部调拨**，建模为内部单位（team）；其余公司为外借方（borrower）。"借出"与"内部调拨"由字典归属区分。
- W-6：K 列人名（王成为/兰孝发）是否作历史 operator；导入 operator 统一填"系统导入/Excel"？→ 确认默认。
- W-7：J 列括号注释（带拖布轮）语义：是否需要结构化（设备属性/备注）还是仅保留到备注？→ 确认默认入备注。
- W-8：无编号设备的"按台数借出"（J=无编号,I>0）如何建模与还原。
- W-9：近义/变体名称（送布机/松布机 等）是否人工归并？
- W-10：借出编号不在本块 F 内的行如何处理（阻断/警告/跳过）？
- W-11：R337 `2018.4` 缺日：补 1 日？还是整行标注异常跳过？
- W-12：J 列"入南库"暗示存在**库房位置**概念（南库/仓库）：第一版是否需要"位置"维度？
- W-13：`财务数量`（E）分段与台账(D)完全一致的前提下，双口径仍需保留双列吗？（建议：不冗余，导入后仅保留 D 语义，E 的差异块单独报告）→ 确认。

## 9. 结论

Excel 语义**主体清晰、边缘含混**：设备主块（A–F）＋借出事件（G–K）可以结构化；数量口径 D=E=2147 自洽；但**编号唯一性、当前在借状态、类别标注**三类问题必须以用户确认为前提进入导入设计，否则会产生错误数据。建议按 `import-rules.md` 的"台账优先、借出历史可选"策略分两步导入。
